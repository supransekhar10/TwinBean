<threat_model>
## ASVS L1 Baseline

This operational plan applies OWASP ASVS Level 1 controls for authentication, access control, input/configuration handling, stored secret protection, and safe error/evidence handling. The existing exact-doctor dependency remains the enforced authorization boundary.

## Trust Boundaries

| Boundary | Description |
|---|---|
| operator -> backend seed CLI | Explicit configuration enters privileged synthetic-data generation and Firestore writes. |
| backend -> Firebase Admin Firestore | Backend-only credentials authorize reads/writes to persistent Cloud Firestore. |
| doctor client -> FastAPI | An untrusted bearer token and patient selector cross the protected HTTP boundary. |
| live runtime -> evidence file | Runtime outputs are reduced to non-secret checksums, paths, statuses, and timestamps. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-2-09 | Tampering | Repeated seed operation | high | mitigate | Run one exact configuration twice, compare manifest checksums and representative owned paths, and prove an unrelated canary is unchanged per D-08. |
| T-2-10 | Information Disclosure | Credentials, bearer token, and evidence | high | mitigate | Keep Application Default Credentials backend-only, send the token only to FastAPI, and prohibit tokens, passwords, keys, or credential paths in documentation/evidence. |
| T-2-11 | Elevation of Privilege | Patient list/detail verification | high | mitigate | Refresh the Firebase token and require exact `role: doctor` through the unchanged FastAPI `require_doctor` dependency per D-11. |
| T-2-12 | Repudiation | Approved-runtime live proof | medium | mitigate | Record UTC time, approved runtime identity, deterministic checksums/counts, representative paths, HTTP statuses, and operator approval in the evidence artifact. |
| T-2-13 | Denial of Service | Seed command | medium | mitigate | Retain the bounded 12-patient invocation and repository batch/document guards; never seed implicitly during API startup per D-07. |
| T-2-SC | Tampering | npm/pip/cargo installs | high | mitigate | Install no package; use the existing audited Firebase Admin dependency and stop for package-legitimacy review if execution discovers an actual install requirement. |
</threat_model>
